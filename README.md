# 🖥️ Student Management Website

A simple web application that allows the teacher to manage students through a dashboard, while the student only needs to enter their ID to view their information and results.

## 🔗 Project Repositories
- Frontend: this repository
- [Backend](https://github.com/eslam-cmd/e-school-server): contains the server logic and databases

## 🛠️ Technologies Used

- NextJS
- MUI
  
## 🚀 How to Run

```bash
npm install
npm start
